Tâches

Toutes les cases à cocher de tous les onglets, au même endroit. Clique le texte pour ouvrir l'onglet, ou coche directement ici sans y aller.

Marges

Toutes les lignes balisées de tous les onglets. Filtre par tag, puis clique une ligne pour aller à l'endroit.

Tags de marge

Symbole, mot court et couleur. Si tu renommes un tag, les lignes déjà écrites avec l'ancien nom ne seront plus reconnues.

Fichier JSON lié

Le carnet s'enregistre automatiquement dans ce fichier (en plus du navigateur) et s'en recharge à l'ouverture s'il est plus récent. Chrome ou Edge requis ; le navigateur peut redemander l'autorisation d'accès au fichier d'une session à l'autre (un clic sur « Synchroniser »). Les images restent dans le navigateur : « Exporter JSON » les inclut.

Mémoire de sauvegarde

Tout est stocké en local dans ce navigateur, sur cet appareil uniquement — rien n'est envoyé ailleurs. Le carnet est stocké dans IndexedDB (quota très large) ; la barre ci-dessous ne mesure plus que le localStorage (tags, préférences d'affichage), limité à ≈5 Mo. Les images sont aussi dans IndexedDB.

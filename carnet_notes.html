Historique des sauvegardes

Une version est enregistrée automatiquement pendant que tu travailles (et systématiquement avant une suppression ou un import). Tout reste en local sur cet appareil. « Tout restaurer » remplace l'intégralité du carnet ; l'autre bouton ne touche qu'à l'onglet actuellement ouvert.

Tags IA

Ces tags s'insèrent dans le texte brut et servent de consigne quand tu envoies vers ChatGPT/Claude. Modifie le nom ou la consigne, ajoutes-en ou supprimes-en — c'est sauvegardé automatiquement sur cet appareil.

Tâches

Toutes les cases à cocher de tous les onglets, au même endroit. Clique le texte pour ouvrir l'onglet, ou coche directement ici sans y aller.

Fichier JSON lié

Le carnet s'enregistre automatiquement dans ce fichier (en plus du navigateur) et s'en recharge à l'ouverture s'il est plus récent. Chrome ou Edge requis ; le navigateur peut redemander l'autorisation d'accès au fichier d'une session à l'autre (un clic sur « Synchroniser »). Les images restent dans le navigateur : « Exporter JSON » les inclut.

Mémoire de sauvegarde

Tout est stocké en local dans ce navigateur, sur cet appareil uniquement — rien n'est envoyé ailleurs. Le carnet et son historique sont stockés dans IndexedDB (quota très large) ; la barre ci-dessous ne mesure plus que le localStorage (tags, préférences d'affichage), limité à ≈5 Mo. Les images sont aussi dans IndexedDB.

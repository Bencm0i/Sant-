Résultat
Format : base + indice + complément, ex. 5PAF1266PMC005A ou 5PAF1266PMC005A_PLAN. Clique plusieurs indices et/ou compléments pour générer toutes les combinaisons d'un coup. "sans" = pas de complément (utile pour avoir les deux). Les indices et compléments ajoutés sont mémorisés (× pour les retirer). Si le complément commence déjà par - ou _, aucun séparateur n'est ajouté.
L'étape nommée "Indice" incrémente automatiquement la dernière lettre du nom (A→B, B→C...) quand elle est cochée. Les autres étapes sont de simples cases à cocher.
